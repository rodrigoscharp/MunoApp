# Painel novo — mockups de referência

Mockups aprovados do painel do restaurante (dashboard, pedidos, cardápio) e o
quadro de referências. Referência visual da implantação; não rodam no app (as
imagens apontam para `/_blob/...`, o armazenamento do quadro). Os números do
dashboard são exemplos: cada métrica sai de dado que o sistema já guarda.

As telas que não têm mockup próprio (cozinha, chats, mesas, motoboys,
pagamentos, assinatura, restaurante) seguem o mesmo sistema: menu lateral,
`CabecalhoDaTela`, cartões de papel e `Selo`, em `src/components/painel/`.
