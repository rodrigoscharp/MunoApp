# Loja nova — mockups de referência

Os arquivos `.dc.html` daqui são os mockups aprovados da nova interface da loja
(cardápio, produto, sacola, acompanhamento e sistema visual). Eles servem de
referência visual para a implantação e não rodam no app: as imagens apontam
para `/_blob/...`, o armazenamento do quadro onde foram desenhados.

Os tokens e as classes que eles usam viraram `--color-loja-*`, `.loja` e
`.manchete` em `src/app/globals.css`, e as peças reaproveitáveis estão em
`src/components/loja/`.
